## About the Project

**NPS for Everything** is a movie review platform that rates films using a **Net Promoter Score (NPS)** instead of a traditional star average. Average ratings tend to get inflated and can hide how split an audience really is, so NPS asks a different question: would people actually recommend this to someone else? Each film's reviews are broken down into promoters, passives, and detractors to produce a score that better reflects how audiences really feel.

### Features

- Browse and search movies, ranked by NPS
- Account sign up, log in, and log out
- Write reviews and see the promoter / passive / detractor breakdown for each film
- View reviews by movie or by user
- Save favorite movies

### Tech Overview

- **Frontend:** React single-page app built with Vite
- **Backend:** Separate REST API handling auth, movies, reviews, and favorites
- **Deployment:** Frontend and API both deployed on Render

# onboarding_class

> **Note:** This repo is coursework for **ACS 4941: Onboarding Into Companies**. It is a personal workspace for job search prep and interview practice, not a portfolio project, so you can skip it.

Course repo: [Tech-at-DU/ACS-4941-Onboarding-into-Companies](https://github.com/Tech-at-DU/ACS-4941-Onboarding-into-Companies)

## What's in here

This repo collects job search prep and interview practice from the course, including:

- **Job search plan & pipeline tracking:** goals, target roles, and the weekly outreach and application tracker
- **Resume & LinkedIn:** drafts and revisions
- **Networking & outreach:** outreach templates and notes from informational interviews
- **Technical interview challenges:** weekly challenge rotation (algorithms, take-homes, debugging, AI-assisted coding rounds)
- **System design:** junior-level design exercises, including an LLM-powered feature
- **Behavioral interviews:** STAR story bank and practice questions
- **Offer evaluation & negotiation:** notes and comparisons
- **30-60-90 day onboarding plan**
